# UI Design Direction — Dayos-Inspired

Reference:
https://getdesign.md/design-md/dayos

The reference is described as an AI-powered business operating system / enterprise AI SaaS / operations-platform visual language.

## Visual principles
Create a polished AI operations console with:
- light neutral base surfaces
- high-contrast typography
- restrained black/charcoal primary text
- subtle gray borders
- soft neutral cards
- one controlled accent color for primary actions and AI states
- small status pills rather than giant decorative badges
- generous spacing and clear section rhythm
- compact but readable data tables
- rounded panels with restrained radius
- subtle elevation only where hierarchy needs it
- minimal decorative gradients
- no excessive glassmorphism
- no dashboard-template clutter

## App shell
Use:
- persistent left navigation
- top bar for org/store context, search if supported by API, notifications/activity entry, and user menu
- primary workspace
- right-side activity/agent panel where appropriate

The right-side activity panel is a core product surface because all org-wide agent activity must be visible there.

## Brand behavior
Do not use Dayos logos, trademarks, exact copy, or proprietary assets.
Use the visual language as inspiration only.

## Typography
Use a modern sans-serif stack with:
- strong page titles
- medium-weight section headings
- compact metadata
- readable body copy
- monospace only for IDs, technical payloads, timestamps, or transcript metadata when useful.

## Motion
Use subtle motion:
- activity feed item arrival
- status transitions
- negotiation turn expansion
- approval success
- transfer confirmation progress

Do not animate critical data in a distracting way.

## Accessibility
- keyboard navigable actions
- visible focus states
- sufficient color contrast
- status never communicated by color alone
- destructive actions require clear confirmation
- screen-reader labels for icon-only controls
